## H6: underestimation event

Y=1[RVAR_CC_30c > 1.5 IVAR]. This is variance exceeding implied variance by 50%, corresponding to volatility ratio sqrt(1.5), not 1.5. Four models:

- A: monthly expanding matured event frequency, smoothed (events+0.5)/(N+1).
- B: standardized log IVAR, sklearn logistic L2 C=1, lbfgs, max_iter=2000, tol=1e-8.
- C: same logistic with log IVAR, log trailing21/63 annualized mean squared daily returns (252), log downside21 semivariance (252 mean min(r,0)^2), negative-return magnitude max(-r_t,0), and log current GARCH30c. Log floor 1e-8 for variance inputs.
- D: same six features, GradientBoostingClassifier, log_loss, 50 trees, depth2, learning_rate .05, min_samples_leaf50, subsample1, random_state1729; all other sklearn 1.7.2 defaults. No feature/architecture search.

Probabilities clipped only for numerical log loss at [1e-6,1-1e-6]. Primary Brier; secondary log loss, ROC-AUC, average precision (PR-AUC convention), 10 fixed-width reliability bins, logistic diagnostic intercept/slope on OOS log odds (not a forecast calibration step), prevalence, precision/recall/FNR at p>=.5. Fixed 10% evaluation alert budget ranks OOS probabilities, descending, ties chronological; ceil(.1N) alerts. This retrospective allocation metric is explicitly not a deployable threshold. Also report chronological alerts above each month's training-score 90th percentile and their actual alert fraction. Never feed evaluation ranks into trading. Strongest simple benchmark is min-Brier A/B; advanced C/D must beat BOTH in family-adjusted comparisons. Practical screening minimum: >=5% relative Brier reduction against strongest A/B AND >=5 percentage-point recall gain at fixed 10% budget. Neither threshold establishes economic utility without a decision cost model.
